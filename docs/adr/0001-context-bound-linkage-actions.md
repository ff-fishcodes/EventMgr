# 绑定执行上下文的联动动作使用 Qt 队列连接

联动动作既可以继续在线程池执行，也可以绑定到外部维护的 QObject 执行上下文。绑定上下文的动作通过每个动作私有的 dispatcher 和 `Qt::QueuedConnection` 调度，使动作遵循 Qt 线程亲和性，同时不向调用方暴露内部调度机制。执行上下文销毁后，动作变为不可用，后续执行安全跳过。动作名称全局唯一，注册后在进程生命周期内不可替换、不可注销；重复注册及空名称、空回调、空上下文、QThread 上下文均被拒绝。

## 影响

- 调用方必须在注册前完成执行上下文的线程配置并维护其生命周期和 event loop。
- 有效启用状态由事件动作开关与动作可用性共同决定；不可用动作仍在界面中显示，但取消勾选并禁用。
- 线程池动作保持最多四路并发和 fire-and-forget；上下文动作每次触发排队一次，并遵循 Qt 的队列顺序语义。
- 模块不提供动作注销或生产环境清空接口，不管理目标线程，也不保证软件关闭时外部上下文队列全部执行完成。
